Templates

Each page kind, before the edition opens.

These screens are the furniture. Public reading needs no account. Suggesting a reading will use GitHub. The bar above lets you preview a role. It does not sign you in.

  • Catalog

    A list of manuscripts. Dense, typographic, one row per witness.

  • Reader

    One line of Hebrew or Aramaic. Select a word. Follow the library for the plate.

  • Work

    A composition across copies. Isaiah first, then the other named works.

  • Lexeme

    Academic morph code first. Seeded BDB/Jastrow gloss. Strong's is a lookup, never the key.

  • Search

    Find a line, a lemma, or a manuscript.

  • Suggest a reading

    The contributor form. Gated until GitHub sign-in exists.

  • Proposal

    A public change record. Anyone can read it. Reviewers vote here later.

  • Review queue

    Open proposals waiting for two peer reviewers.

  • Account

    Who you are, your tier, and how credit accrues.

  • Sign in

    GitHub only. The start of the OAuth route.

  • About

    Method, photographs, and the licenses on the two Hebrew sources.

opendeadsea.org. Photographs stay at the libraries that published them.
