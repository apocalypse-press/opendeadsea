Open Dead Sea

Status: Coming soon

The scrolls, versioned.

A public corpus of the Dead Sea Scrolls. Consensus text and translations. Edits proposed in the open and merged only after review. Each manuscript links out to the library that holds the official plates.

קול קורא במדבר

Isaiah 40:3. Wording attested among the Qumran Isaiah copies.

What you will be able to do

Read the consensus text without an account. Export data. Follow every proposed reading as a public pull request.

When the editor opens, a free GitHub account is enough to suggest a line or token change. Reviewers vote. Merges rebuild the static site.

  1. Public reader

    No login. Consensus text, translations, links to official plates, and the full discussion history.

  2. Contributor

    GitHub OAuth. Submit an edit request. Comment on diffs. Earn reputation when work is accepted.

  3. Peer reviewer

    Reputation above 500, or academic verification. Vote on incoming requests. Two approvals merge a contributor request.

  4. Maintainer

    SSH key in CODEOWNERS. Emergency hotfixes, trust overrides, and academic verification.

Hosted on the free edge

The corpus lives in Git. Reputation lives in D1. The public site is Cloudflare Pages. We do not host gated multi-spectral plates. Each manuscript record points to the official viewer. There is no paid compute in the edit path. Your GitHub identity opens the pull request.
